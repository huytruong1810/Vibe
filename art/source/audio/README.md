# Music scores (doctrine AUD)

- `scores/*.json`: original compositions in the tracker-style score format (AUD-5.1).
  `hearthwild-motif.json` is the main leitmotif every theme quotes (AUD-3.1).
- `tools/render_score.py`: validates a score and renders a WAV preview into gitignored
  scratch. See the `music-score` skill for the workflow.
