# docs/doctrine: read-only

This folder is the Hearthwild doctrine. **No agent may create, edit, move or delete
anything here** (DOC-1). Only the director, or Claude in a session with the director,
amends it.

- Cite rules by ID (for example `ART-4.2`) and quote them; don't paraphrase from memory (DOC-4).
- To change a rule, write `docs/team/proposals/NNN-title.md` (DOC-3, TEAM-6).
